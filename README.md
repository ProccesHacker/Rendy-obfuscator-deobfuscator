# Rendy Deobfuscator

Деобфускатор для файлов, обфусцированных Rendy Obfuscator.

## Возможности

- извлекает данные из обфусцированного файла;
- восстанавливает AST;
- сохраняет восстановленный Python-код

## Использование

Запуск:

```bash
python deobf.py
```

После запуска укажи путь к файлу или папке, которые надо деобфусцировать.

Также можно использовать из Python:

```python
from deobf import process_data_2

process_data_2("obfuscated.py")
```

- Python 3.10+

## Примечание

Инструмент предназначен для деобфускации файлов что были обфусцированны RendyObfuscator
